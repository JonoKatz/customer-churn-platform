# Customer Churn Prediction Platform

An end-to-end machine learning platform that predicts customer churn using real-world telecommunications data.

## Project Overview

Customer churn is one of the biggest challenges faced by subscription-based businesses. This project aims to identify customers who are likely to cancel their service, allowing businesses to take proactive measures to retain them.

The project will evolve from a machine learning notebook into a production-ready application with a web interface, API, explainable AI, and deployment.

---

## Project Goals

- Predict customer churn using machine learning
- Compare multiple classification models
- Explain predictions using SHAP
- Build an interactive Streamlit application
- Expose predictions through a FastAPI API
- Deploy the application online
- Demonstrate professional software engineering practices
